Ámbito de variables y clases

Ámbito de variables

Una variable declarada fuera de una función es global; una declarada dentro es local a esa función. Hasta aquí, como en la mayoría de lenguajes.

$contador = 0;

function verContador() {
    echo $contador; // Aviso: variable indefinida. $contador no es visible aquí.
}

verContador();
TipAnalogía Java

En Java, una variable de instancia es visible en todos los métodos de la clase sin nada especial. En PHP, una variable global no entra automáticamente en una función: hay que declararla con global. Es la sorpresa más común al llegar a PHP desde Java.

Para acceder a una variable global dentro de una función, se declara explícitamente:

$contador = 0;

function incrementar() {
    global $contador;
    $contador++;
}

incrementar();
incrementar();
echo $contador; // 2

static declara una variable local que conserva su valor entre llamadas sucesivas a la misma función:

function siguienteId() {
    static $ultimoId = 0;
    $ultimoId++;
    return $ultimoId;
}

echo siguienteId(); // 1
echo siguienteId(); // 2
echo siguienteId(); // 3
AdvertenciaErrores frecuentes

Olvidar global es la causa más habitual de “esta variable no se actualiza” en scripts sencillos de PHP. Si una función necesita leer o modificar una variable externa, decláralo explícitamente o, mejor aún, pásala como parámetro y devuélvela (es más limpio que depender de global).

TipCuriosidad

PHP permite variables variables ($$nombre), donde el valor de una variable se usa como nombre de otra:

$clave = 'color';
$$clave = 'azul'; // equivale a $color = 'azul'
echo $color; // azul

Clases y objetos

Una clase es una plantilla; un objeto es una instancia concreta de esa clase.

NotaConcepto clave

class define la plantilla. new crea un objeto. -> accede a propiedades y métodos del objeto.

class Producto {
    public string $nombre;
    public float $precio;

    public function descripcion(): string {
        return "{$this->nombre}: {$this->precio} €";
    }
}

$p = new Producto();
$p->nombre = 'Teclado';
$p->precio = 25.90;
echo $p->descripcion(); // Teclado: 25.9 €

Más ejemplos rápidos, mismo patrón:

class Libro {
    public string $titulo;
    public int $paginas;
}

$l1 = new Libro();
$l1->titulo = 'PHP para todos';
$l1->paginas = 320;

$l2 = new Libro();
$l2->titulo = 'Domina Laravel';
$l2->paginas = 210;

echo $l1->titulo . ' - ' . $l1->paginas . ' páginas'; // PHP para todos - 320 páginas
echo $l2->titulo . ' - ' . $l2->paginas . ' páginas'; // Domina Laravel - 210 páginas
class Coche {
    public string $marca;
    public int $velocidad = 0;

    public function acelerar(int $incremento): void {
        $this->velocidad += $incremento;
    }
}

$c = new Coche();
$c->marca = 'Toyota';
$c->acelerar(30);
$c->acelerar(20);
echo $c->velocidad; // 50

Actividades

EJ1 · Registro de libros con contador global

Crea una clase Libro con propiedades titulo y autor. Usando una variable global (no una propiedad de la clase) y la palabra clave global vista en esta sección, lleva la cuenta de cuántos objetos Libro se han creado en total, incrementando el contador cada vez que instancies uno nuevo con new Libro(...).

Pista: la forma más directa es incrementar el contador global justo después de cada new Libro(...), sin tocar la clase; para un contador que viva realmente “dentro” de la clase sin depender de una variable externa, tendrás que esperar a la sección de clases estáticas.

TipCómo comprobarlo

Crea los libros desde una función (por ejemplo, registrarLibro()) que declare el contador con global. Después de crear dos libros:

registrarLibro('PHP para todos', 'Ana');
registrarLibro('Domina Laravel', 'Manel');
echo 'Libros creados: ' . $contador;   // Libros creados: 2

Para entender el fallo típico, quita global dentro de la función y ejecuta otra vez: el contador se queda en 0 y PHP avisa de “variable indefinida”, porque la función trabajaba con su propia variable local.
